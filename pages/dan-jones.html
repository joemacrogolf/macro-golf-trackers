Max intent
Every explosive rep as fast and powerful as you can. Pick a med ball or resistance that lets you move quickly. Mark each set Fast, or Slowed if the speed dropped.
Load
After each set, enter the kg, reps and RPE. The next set shows a suggested load: one step lighter if it felt a full point harder than the target or the speed dropped, one step heavier if it felt a full point easier. Your first set each session is suggested from your last session. Tap the Rest button on a block to start the countdown.
